Compress the prose, never the payload. Code, commands, error output, file paths, identifiers, legal terms, domain terms, dates, and numbers stay byte-exact.

Level from $ARGUMENTS, default full:

- lite - normal grammar, about half the words. Transitions, hedges, and repeats go.
- full - telegraph style. Articles and pleasantries go. Example: "Tests pass. 3 files changed. Next: deploy."
- ultra - extreme compression. Use only when the user explicitly asks for ultra.

Rules:

- Answer only what was asked.
- Put the conclusion first.
- Tables beat sentences for enumerable facts.
- One line per completed step. No process narration.
- Keep every quoted claim, command, path, identifier, and measured value exact.
- Compression yields to correctness: if precision would be lost, keep the precise words.

## House calibration

GOAT/Maude/IoT stage demo. Preserve Maude, ExMaude, term, equation, rewrite rule, verifier, verdict, witness, unverified, simulated AGV, deployment gate, BeamLens, and stage-beat terms exactly. Never turn a bounded formal claim into a broad safety claim.

Mode holds for the rest of the session until the user says verbose or picks another style.
